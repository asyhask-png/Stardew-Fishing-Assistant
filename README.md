# Stardew-Fishing-Assistant# Fishing Assistant

Помощник для рыбалки в **Stardew Valley 1.6**: обнаруживает пузырьковые места, рисует маршрут до них
(в том числе через переходы между локациями) и умеет полностью автоматически рыбачить — забрасывать,
подсекать, идеально вести планку мини-игры и собирать сундуки с сокровищами. Весь функционал
разбивается на независимые модули и включается отдельно.

Вся автоматизация **локальная**: мод управляет только вашим фермером и никогда не отправляет
сообщения другим игрокам.

## Поддерживаемые версии

| Компонент        | Версия                                            |
|------------------|---------------------------------------------------|
| Stardew Valley   | 1.6.x (проверено на **1.6.15**, build 24356)      |
| SMAPI            | 4.0+ (проверено на **4.5.2**)                     |
| .NET             | .NET 6 (рантайм игры); сборка — SDK 6/8           |
| Платформа        | Windows (MonoGame DesktopGL)                      |

Мод ссылается только на публичные члены установленных сборок; все ключевые поля/методы
(`FishingRod`, `BobberBar`, `GameLocation.fishSplashPoint` и т. д.) сверены с реальной сборкой 1.6.15
дизассемблированием — см. `docs/api_reflection_report.txt` и `docs/api_il_disassembly.txt`.

## Установка

1. Распакуйте архив (или папку `dist/FishingAssistant`) в папку `Mods` игры:
   `<игра>/Mods/FishingAssistant/`.
2. Запустите игру через SMAPI.
3. Файл `config.json` создаётся автоматически при первом запуске.

## Сборка из исходников

Требуется .NET SDK (6 или 8). Игра должна быть установлена.

```powershell
# путь к игре подставляется автоматически; при другом расположении:
dotnet build src/FishingAssistant/FishingAssistant.csproj -c Release -p:GamePath="C:\Games\Stardew Valley"
```

Готовая сборка появится в `src/FishingAssistant/bin/Release/`. Скрипт `package.ps1` собирает
проект, тесты, формирует папку мода и ZIP-архив:

```powershell
powershell -File package.ps1 [-GamePath "..."]
```

Запуск тестов чистых алгоритмов (поиск пути, фильтр, приоритеты сокровищ, автомат):

```powershell
dotnet run --project tests/FishingAssistant.Tests -c Release
```

## Возможности и включение

### Обнаружение пузырьков (`BubbleDetectionEnabled`)
Каждую секунду сканируются все загруженные локации и читаются официальные поля игры:
* `GameLocation.fishSplashPoint` — обычные пузырьки;
* `GameLocation.fishFrenzyFish` — «рыбный угар» (Fish Frenzy), у него увеличенный радиус поклёвки.

Декоративная анимация воды игнорируется: читается только авторитетное состояние локации,
поэтому обычные пузыри не путаются с эффектами. При обнаружении нового места выводится локальное
HUD-сообщение вида «Обнаружено пузырьковое место: Лес Синдерсэп — клетка 42, 18».
Повторные сообщения не спамятся (дедупликация по ключу «локация|x|y|тип»).

Настройка `TrackedBubbleKinds` позволяет следить за обоими типами или только за одним.

### Маршрут (`RouteEnabled`)
Яркая анимированная штриховая линия от игрока к цели:
* поиск пути A* по клеткам с проверкой проходимости (`isTilePassable`, вода, границы карты);
* линия ведёт не в воду, а к ближайшей проходимой клетке берега, с которой возможен заброс;
* пересчёт при движении игрока (троттлинг ~400 мс), исчезает при пропаже пузырьков, отключении
  функции, а также во время меню/событий/кат-сцен;
* настраиваются цвет, прозрачность, толщина и анимация.

**Между локациями:** строится граф переходов (варпы + двери зданий + лодка Beach↔IslandSouth),
находится кратчайшая цепочка локаций (BFS), затем для каждой части прокладывается путь A*:
текущая локация → нужный выход, после перехода маршрут пересчитывается, финальная часть ведёт
к берегу. Если полный путь построить нельзя, показывается направление к ближайшему известному
переходу и уведомление. Граф кешируется на день и перестраивается после смены дня/загрузки
или догрузки модовых карт.

Выбор цели (`TargetSelection`): `CurrentLocationFirst` / `NearestByRoute` / `Manual`
(клавиша следующей цели).

### Авторыбалка (`AutoFishingEnabled`)
Конечный автомат состояний `Idle → SelectingTarget → PreparingCast → Casting → WaitingForBite →
Hooking → FishingMinigame → HandlingCatch → Cooldown` (+ `Paused` / `ErrorRecovery`) — без блокирующих
задержек, всё через тики SMAPI.

* заброс выполняется штатной анимацией удочки: сила подбирается по формуле дальности игры
  (уровень рыбалки + уровень удочки) и уточняется адаптивной калибровкой по факту приземления поплавка;
* подсечка — ровно в окно поклёвки (`isNibbling`), тем же вызовом, что и нажатие кнопки игроком;
* паузы при открытом меню, диалоге, событии, заполненном инвентаре, смене локации, усталости;
  выход из паузы продолжает цикл;
* без пузырьков можно ловить лучшую доступную воду (`AutoCastWithoutBubbles`) или ждать пузырьки.

Автоходьбы к месту нет: мод ведёт вас маршрутом, а заброс выполняет, когда игрок стоит у воды
в пределах досягаемости удочки. Игрок не телепортируется и карта не изменяется.

### Идеальная мини-игра (`PerfectFishingEnabled`)
Планка удерживается внутри рыбы регулятором с мёртвой зоной, учётом инерции и предсказанием
торможения. Прогресс, позиция планки и результат напрямую не изменяются — мини-игра проходится
обычной физикой игры (стремится к статусу Perfect).

**Как реализовано управление:** поле `BobberBar.buttonPressed` игра каждый кадр перезаписывает из
сырого ввода мыши/клавиатуры (подтверждено IL-кодом), поэтому «виртуальный клик» невозможен.
Мод после игрового апдейта добавляет ускорение ±0.25 px/тик² к `bobberBarSpeed` — это ровно тот же
эффект, который даёт удержание/отпускание кнопки. Настройки: погрешность, интенсивность,
предсказание инерции, безопасный режим (аварийное отключение модуля при неожиданной структуре
мини-игры).

### Сбор сокровищ (`TreasureMode`)
Отдельный переключатель, независимый от идеальной рыбалки: `Off` / `SafeOnly` / `AlwaysTry`.
Рыба всегда важнее: переключение к сундуку допускается только при запасе прогресса и стабильном
удержании; после заполнения шкалы сундука планка возвращается к рыбе.

### Фильтр улова (`FishFilterMode`)
Проверяет только новый улов текущей рыбалки (окно после закрытия мини-игры); ранее лежавшие в
инвентаре предметы не трогаются. Поддерживает ID, квалифицированные ID `(O)129` и отображаемые
названия, минимальное/максимальное качество, белый/чёрный списки, пользовательскую защиту.

**Встроенные защиты (не отключаются):**
* легендарная рыба (ID 159, 160, 163, 682, 775, 898–901 и контекст-тег `fish_legendary`);
* квестовые и особые предметы (`questItem`, категория −20, `specialItem`);
* предметы, которые игра запрещает выбрасывать (`canBeTrashed() == false`);
* предметы из сундуков с сокровищами этой рыбалки;
* всё, что не удалось уверенно классифицировать.

Примеры в `config.json`:

```json
"FishFilterMode": "Whitelist",
"FishFilterBehavior": "NotifyOnly",
"MinimumQuality": "Gold",
"AllowedFish": [ "129", "(O)136", "Carp" ],
"BlockedFish": [],
"ProtectedFish": [ "167", "(O)842" ]
```

`FishFilterBehavior`: `Remove` (удалить), `DropNearby` (выбросить рядом, если безопасно),
`NotifyOnly` (только уведомление). Все действия пишутся в журнал (консольная команда `fa_log`).
По умолчанию включён самый безопасный вариант — фильтр выключен.

## Горячие клавиши (по умолчанию)

| Клавиша | Действие                                        | Поле конфига              |
|---------|--------------------------------------------------|---------------------------|
| **F6**  | Полное вкл/выкл мода (мгновенно освобождает управление) | `MasterToggleKey` |
| F7      | Показать/скрыть маршрут                          | `RouteToggleKey`          |
| F8      | Авторыбалка                                      | `AutoFishingToggleKey`    |
| F9      | Идеальная мини-игра                              | `PerfectFishingToggleKey` |
| F10     | Режим сокровищ по кругу Off→SafeOnly→AlwaysTry   | `TreasureToggleKey`       |
| F11     | Следующее пузырьковое место                      | `NextTargetKey`           |

Клавиши меняются в `config.json` (формат SMAPI SButton, например `"OemPeriod"`, `"LeftAlt"`)
или через GMCM. F6 работает всегда, даже когда мод выключен.

## Конфигурация

`config.json` создаётся автоматически; все поля типизированы и документированы в коде
(`ModConfig.cs`). Есть необязательная интеграция с **Generic Mod Config Menu**
(мод не требует GMCM для работы).

Консольные команды SMAPI: `fa_status`, `fa_toggle <autofish|perfect|route|enabled>`,
`fa_log`, `fa_scan`.

## Ограничения (честно)

1. **Видимость пузырьков ограничена загруженными локациями.** Игра хранит `fishSplashPoint`
   только у созданных объектов локаций; шахты/вулкан генерируют этажи на лету — пузырьки там
   появятся в трекере только после посещения этажа. Мод не симулирует данные, которых у игры нет.
2. **Нет автоходьбы.** Маршрут доводит игрока до берега визуально; заброс выполняется только если
   вы стоите у воды в пределах дальности удочки. Если точное попадание в пузырьки невозможно
   (слабая удочка/геометрия берега), мод сообщит и бросит в ближайшую допустимую воду.
3. **Проверка линии полёта упрощённая:** промежуточные клетки должны быть водой либо свободной
   землёй; высокие объекты, над которыми поплавок мог бы перелететь, трактуются консервативно
   как препятствие.
4. **Граф локаций не учитывает время работы дверей магазинов и расписания NPC** — учитываются все
   варпы/двери, присутствующие в картах. Закрытые на данный момент двери могут попасть в маршрут.
5. **Управление мини-игрой** добавляет ускорение планке после игрового апдейта (лаг ≤1 кадра);
   при очень высоких значениях `MinigameStrength` поведение может отличаться от человеческого.
6. **Fish Frenzy:** увеличенный радиус поклёвки применяется самой игрой, когда поплавок попадает
   в зону; отдельной механики у мода нет, есть только отдельный тип в трекере/настройках.
7. **Мультиплеер:** автоматизация действует только на локального фермера; HUD-сообщения
   локальны. В кооперативе мод не тестировался командой, но не содержит сетевой логики.

## Совместимость

* Моды, которые тоже автоматизируют рыбалку (Auto Fish, Easy Fishing, Skip Fishing Minigame и
  подобные), конфликтуют по смыслу. При обнаружении таких модов выводится предупреждение;
  настройка `RespectConflictingMods` управляет этим поведением.
* Если структура `BobberBar` отличается от ожидаемой (другая версия игры/патчер), модуль идеальной
  рыбалки безопасно сам отключается — остальной мод продолжает работать.
* GMCM опционален; без него настройки доступны в `config.json`.

### Соответствие сценариям проверки (§16)

| # | Сценарий | Покрытие |
|---|----------|----------|

| 8 | Меню открылось посреди авторыбалки | FSM `Paused` c возобновлением |
| 9 | Смена локации | `OnLocationChanged` — безопасное прерывание цикла |
| 10 | Инвентарь полон | проверка перед забросом + уведомление, пауза |
| 11 | Появился сундук | `TreasureRiskModel` (юнит-тесты) |
| 12 | Сокровища отключены | `TreasureMode.Off` игнорирует сундуки |
| 13 | Запрещённая рыба | движок фильтра (юнит-тесты) |
| 14 | Легендарная/квестовая рыба | встроенные защиты (юнит-тесты) |

| 16 | Пользовательская карта | все обращения к картам обёрнуты в try/catch; граф догружается по `LocationListChanged` |

| 18 | Мультиплеер | локальность действий; сетевых вызовов нет |

полноценный игровой прогон требует запущенной игры — рекомендован как ручной шаг.

## Структура проекта

```
FishingAssistant/
├── src/FishingAssistant/          исходники мода (+ manifest.json, i18n/)
│   ├── Pure/                      чистые алгоритмы без игровых типов (тестируемые)
│   ├── Bubbles/ Routing/ Rendering/

│   └── ModEntry.cs ModConfig.cs CompatibilityManager.cs GmcmApi.cs
```
